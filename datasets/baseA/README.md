# Base A

## Purpose

`Base A` is the primary small healthy reference graph for `MASynReas`.

It is designed to support:
- clean `apriori` runs
- clean `aposteriori` runs
- first controlled mutations for the early dataset scenarios

## Design Principles

This graph is intentionally:
- small enough to inspect manually
- coherent with the NORIA-O modeling style used by the project
- rich enough to exercise all level-1 families without introducing intended anomalies

In particular:
- every `noria:Resource` has at least one interface
- every application has both a module and at least two supporting resources
- every service has visible resource coverage through the full service -> module -> application -> resource chain
- every event has a timestamp, a related element, a managed object, and a proposed repair action
- every ticket is linked to an event and to the impacted application and resource
- every change request has both scheduled and actual time information

## Contents

`baseA.ttl` contains:
- 2 services

- 2 applications
- 6 resources
- 8 interfaces
- 4 network links
- 2 procedures

- 2 events
- 2 trouble tickets

## Intended Use

This graph is the base for:
- `DS01_clean_baseA`
- the partial-evidence scenarios derived from `Base A`
- the first integrated anomaly scenarios generated by local mutations
